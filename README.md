## 1. نبذة عن المشروع

**M-Trade Tools — أدوات التاجر الذكي** هو نظام مبسط لمساعدة التجار وأصحاب المتاجر الإلكترونية على تحليل ربحية المنتجات قبل اتخاذ قرار الشراء أو البيع.

يتيح النظام إدخال تكاليف المنتج الأساسية ثم يحسب تلقائياً:

- تكلفة المنتج المتغيرة.
- هامش المساهمة.
- صافي الربح لكل وحدة.
- إجمالي الإيرادات.
- إجمالي التكاليف.
- صافي الربح.
- هامش الربح.
- ROI.
- السعر المستهدف.
- نقطة التعادل.
- التقييم التجاري للمنتج.

الهدف الأساسي هو تحويل حسابات الربحية من عمليات يدوية إلى أداة سريعة لاتخاذ القرار.
